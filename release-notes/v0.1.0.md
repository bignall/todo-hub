# To-do Hub 0.1.0

First release.

- **Task List** with one-line quick add (title, category, priority, due date, optional time, repeat) and one-click tick-off with Undo.
- **Sorted by what needs doing first:** overdue, due today, then priority, with due-soon tasks moved up.
- **Views:** Up next, By category, Today, Done; filter by category or source.
- **Due times:** a timed task counts as overdue once its time passes; on the same day, timed tasks come first.
- **Repeating tasks** add their next copy when completed.
- **Menu badge** for overdue and due-today tasks, and a **dashboard widget**.
- **Private site** option for a site that only holds your list.
- **PHP API** for other plugins: `todo_hub_add()`, `todo_hub_complete()`, keys that prevent duplicates, and `todo_hub_task_completed` hooks.
