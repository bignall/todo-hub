# To-do Hub 0.2.0

One list for all your sites.

- **Connector mode** (To-do → Settings → Role): a site sends its tasks to a hub on another site. Plugins keep calling `todo_hub_add()`, `todo_hub_complete()` and the rest exactly as before.
- **REST API** on the hub at `/wp-json/todo-hub/v1`, logged in with an application password. A new **To-do Connector** role is made for connected sites.
- **Completion callbacks:** for tasks added with `'notify' => true`, the hub tells the site when they're done or reopened, so `todo_hub_task_completed` fires on that site. Failed deliveries are retried for about 14 hours. The connected site confirms every callback with the hub before acting on it.
- **Works offline:** changes made while the hub can't be reached wait in an outbox and are sent in order every five minutes.
- Tasks from connected sites show which site they came from, and keys are kept separate per site.
