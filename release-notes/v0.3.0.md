# To-do Hub 0.3.0

Your dated tasks on Google Calendar.

- **Google Calendar sync** (To-do → Settings → Google Calendar, on the hub). Tasks with a due date go on a "To-do" calendar in your Google account: all-day events for tasks with only a date, and events at the due time (30 minutes by default) for tasks with a time. The event's description has the task's notes, its link and a link back to the task.
- Events follow the task: changed when the task changes, ticked (✓, shown as free) or removed when it's done, back when it's reopened, and gone when the due date is cleared or the task is trashed or deleted. Tasks from connected sites are included.
- **Only its own calendar:** To-do Hub asks for the `calendar.app.created` scope, so it can't see or change your other calendars. It's one way: changes in Google Calendar aren't copied back.
- **Reliable:** changes go out right away; anything Google can't take is retried every five minutes, and everything is checked again daily. Only events that would look different are sent.

## Setting up

You need your own Google OAuth client (free): enable the Google Calendar API in the Google Cloud console, set the OAuth consent screen's publishing status to **In production** (in Testing, Google ends the connection after 7 days), and create a **Web application** client with the redirect URI shown on the settings page. Then enter the client ID and secret and press **Connect Google Calendar**. The README has the steps.
